# ScreenMagnet changes

## 0.84 — release-readiness preview

- Windows setup and portable builds now use the patched sender source included with the package.
- Windows locates installed capture dependencies without relying on a refreshed shell PATH; pairing state uses the current user's data folder.
- The online installer verifies official runtime downloads and reports prerequisite failures.
- Linux AppImage setup adds the application menu entry and icon without sudo; removal retains personal data.
- Packages include application/dependency source archives and original license notices.
- The settings window uses the official PayPal support link and directs packaged updates to Releases.

Real receiver pairing, screen/audio capture and multi-monitor behavior remain hardware-validation tasks. Automated checks do not establish those results.
